# 人物分级 / Character Tiering

SillyTavern / TauriTavern 前端扩展：根据当前剧情自动维护角色的上下文等级。

- L0 无关：不注入
- L1 相关：短档
- L2 在场：现场档
- L3 焦点：完整档

## 安装
在 SillyTavern / TauriTavern 的扩展安装界面粘贴：

https://github.com/fishingadmiral-2/character-tiering

## v0.1.0
这是首个可安装测试版。当前提供角色注册、自动关键词升档、在场/离场/焦点启发式判断、手动分级面板，以及生成前人物资料注入。

> 建议先用少量测试角色验证。自动读取既有世界书并拆分档案将在后续版本加入。
